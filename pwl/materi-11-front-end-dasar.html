1. Pengantar Front End Pengantar

Kelompok proyek dibentuk mulai pertemuan ini. Sub-CPMK 6–8 (Pertemuan 11–15) dikerjakan berkelompok, maksimal 3 orang per kelompok. Backend yang kalian bangun individu di Pertemuan 1–10 menjadi dasar proyek kelompok yang dikembangkan bersama sampai akhir semester.

Sampai Pertemuan 10, kita sudah membuat API, yaitu program yang menerima request dan membalasnya dengan JSON. Mulai pertemuan ini, kita beralih ke bagian yang dilihat pengguna, yaitu front end. Front end adalah aplikasi yang berjalan di browser, meminta JSON dari API, lalu menampilkannya di halaman.

1.1 Mengapa Pakai Framework?

Di Pertemuan 1–2 kita sudah menulis JavaScript yang mengubah halaman lewat DOM. Untuk halaman kecil itu cukup. Untuk aplikasi dengan daftar, filter, dan form, kita harus mengingat sendiri bagian halaman mana yang perlu diperbarui setiap data berubah.

JavaScript murni (imperatif)
Data berubah → kita cari elemennya, hapus isinya, buat elemen baru satu per satu, lalu pasang lagi. Lupa satu langkah, tampilan dan data tidak sinkron.
Framework (deklaratif)
Kita cukup menulis tampilan itu seperti apa untuk data tertentu. Saat data berubah, framework yang memperbarui halaman.

1.3 Apa Itu Vue?

Vue (dibaca “view”) adalah framework JavaScript untuk membangun UI. Vue dibuat oleh Evan You dan pertama kali dirilis pada tahun 2014. Sekarang Vue bersifat open source dan dikembangkan oleh komunitas.

  • Template berbasis HTML. Tampilan ditulis dengan HTML biasa yang diberi sintaks tambahan ({{ nama }}, v-for, @click). Bagi yang sudah terbiasa dengan Blade, bentuknya terasa akrab.
  • Reactivity otomatis. Data yang dibungkus ref dipantau Vue. Saat nilainya berubah, bagian halaman yang memakainya diperbarui sendiri.
  • Satu file per component (.vue). HTML, JavaScript, dan CSS satu component dikumpulkan dalam satu file.
  • “Progressive”. Vue bisa dipakai bertahap, dari sekadar menghidupkan satu bagian halaman sampai aplikasi lengkap. Di mata kuliah ini kita memakai bentuk aplikasi lengkap.
  • Banyak hal sudah tersedia: v-model untuk form, CSS yang terbatas per component (scoped), dan library resmi untuk routing (Vue Router) serta state bersama (Pinia).
Kita memakai Vue 3 dengan gaya Composition API (<script setup>, ref, computed). Tutorial lama di internet sering memakai gaya Options API (data(), methods). Itu Vue yang sama dengan cara penulisan berbeda; bila bertemu, jangan bingung.

1.4 Apa Itu React?

React adalah library JavaScript untuk membangun UI. React dibuat di Facebook (sekarang Meta) dan dirilis sebagai open source pada tahun 2013.

  • Library, bukan framework lengkap. React hanya mengurus tampilan: component dan state. Hal lain seperti routing tidak ikut; kita memasang library terpisah (React Router di Section 14). Vue pun memakai library terpisah untuk routing, tetapi yang resmi sudah disiapkan timnya.
  • Component adalah fungsi JavaScript yang mengembalikan tampilan, ditulis dengan JSX (sintaks mirip HTML di dalam JavaScript). Hampir semuanya JavaScript biasa: perulangan dengan .map(), kondisi dengan ternary.
  • Data mengalir satu arah: dari component induk ke anak lewat props. Perubahan data dilakukan lewat fungsi khusus (setter milik useState), lalu React menggambar ulang tampilan.
  • Ekosistem sangat besar dan banyak dipakai di industri. Konsep yang sama juga dipakai di React Native untuk aplikasi mobile.
Satu ide yang dipakai keduanya: Virtual DOM. Mengubah DOM asli (pohon elemen halaman, Pertemuan 1–2) itu mahal. Vue dan React menyimpan salinan ringan dari tampilan di memori; saat data berubah mereka membandingkan salinan lama dan baru, lalu hanya mengubah bagian DOM yang benar-benar berbeda. Kita tidak perlu mengurusnya sendiri. Berkat mekanisme ini, menulis “tampilan untuk data tertentu” tetap bisa berjalan cepat.

2. Buat Project Vue Indikator 6.1

Vue bisa dipakai dengan dua cara: lewat CDN (cukup satu file HTML) atau lewat project yang dibuat dengan Vite. Kita mulai dari CDN supaya terlihat apa yang sebenarnya dikerjakan Vue, lalu pindah ke project yang akan dipakai sampai akhir pertemuan.

2.1 Vue dari CDN (Tanpa Project)

Vue tidak harus dipasang lewat project. Kita bisa memakainya hanya dengan satu file HTML, karena Vue tersedia di CDN (Content Delivery Network): server yang menyimpan file library sehingga bisa dipanggil lewat satu tag <script>, tanpa npm install. Cara ini paling sederhana untuk mencoba Vue.

Buat file baru bernama vue-cdn.html di folder mana saja, lalu isi dengan kode berikut:

vue-cdn.html
<!DOCTYPE html>
<html lang="id">
<head>
  <meta charset="UTF-8">
  <title>Vue dari CDN</title>
  <script src="https://unpkg.com/vue@3.5.44/dist/vue.global.js"></script>
</head>
<body>
  <div id="app">
    <h1>Daftar Mahasiswa</h1>
    <p>Semester: {{ semester }}</p>
    <button @click="semester++">Naik semester</button>
  </div>

  <script>
    const { createApp, ref } = Vue

    createApp({
      setup() {
        const semester = ref(6)
        return { semester }
      }
    }).mount('#app')
  </script>
</body>
</html>

Penjelasan bagian yang penting:

  • <script src="...vue.global.js"> memuat Vue dari CDN dan menyediakan object global Vue. Versinya ditulis tetap (3.5.44) supaya hasilnya sama dengan yang kita pakai di project nanti.
  • <div id="app"> adalah tempat Vue bekerja. HTML di dalamnya dibaca Vue sebagai template, jadi {{ semester }} dan @click ditulis langsung di HTML.
  • ref(6) membuat data yang dipantau Vue, sama seperti di Section 3. Fungsi setup() mengembalikan data yang boleh dipakai template.
  • createApp({ ... }).mount('#app') membuat aplikasi Vue lalu memasangnya ke elemen #app.

Cara menguji

  1. Simpan file, lalu buka di browser (klik dua kali, atau seret ke jendela browser). Komputer perlu terhubung ke internet karena Vue diambil dari CDN.
  2. Tampil Semester: 6. Klik Naik semester: angka bertambah tanpa refresh halaman.
  3. Di tab Console muncul pesan You are running a development build of Vue. Ini normal untuk versi belajar. Untuk dipakai sungguhan, ganti vue.global.js dengan vue.global.prod.js.

2.2 Sebelum Mulai: npm, npx, dan Vite

Sebelum membuat project, ada tiga hal yang perlu dipahami karena akan terus muncul: npm, npx (lewat perintah npm create), dan Vite.

b. npx dan npm create: Menjalankan Program Tanpa Memasangnya

Untuk membuat project baru kita butuh sebuah generator, program yang menyusun folder dan konfigurasi awal supaya tidak ditulis satu per satu. Generator itu tidak perlu dipasang permanen, cukup dijalankan sekali. Untuk keperluan ini kita memakai npx, yang mengunduh sebuah paket dari npm ke tempat sementara, menjalankan programnya, lalu selesai.

npm create vite@latest nama-project adalah singkatan dari npm init vite@latest nama-project, yang artinya: “cari paket bernama create-vite di npm, jalankan, dan beri nama project nama-project”. Karena itu di output nanti tertulis > npx dan > cva ...: npm memanggil npx, dan cva adalah nama program di dalam paket create-vite.

c. Vite: Menjalankan dan Membangun Project Front End

Vite (dibaca “vit”, bahasa Prancis untuk “cepat”) adalah build tool untuk project front end. Dibuat oleh Evan You, pembuat Vue, tetapi tidak terikat pada Vue: React dan framework lain juga memakainya.

Mengapa dibutuhkan? Browser hanya mengerti HTML, CSS, dan JavaScript standar. Padahal kode kita memakai file .vue dan .jsx (bukan format standar), dan import { ref } from 'vue' (browser tidak tahu di mana “vue” berada). Vite menerjemahkan semua itu menjadi sesuatu yang bisa dijalankan browser.

2.3 Buat dan Jalankan

Sekarang kita buat projectnya. Project front end ini terpisah dari api-mahasiswa; keduanya baru dihubungkan di Pertemuan 12. Karena itu kita tidak bekerja di dalam folder api-mahasiswa, tetapi membuat folder baru bernama belajar-frontend yang nanti menampung project Vue dan project React.

Buka terminal, pindah ke lokasi yang mudah ditemukan (misalnya di samping folder api-mahasiswa, bukan di dalamnya), lalu buat foldernya:

$ mkdir belajar-frontend $ cd belajar-frontend

Di dalam folder itu, buat project Vue, pasang dependency-nya, lalu jalankan:

$ npm create vite@latest vue-mahasiswa -- --template vue --no-interactive $ cd vue-mahasiswa $ npm install $ npm run dev
