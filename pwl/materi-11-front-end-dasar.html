1.1 Mengapa Pakai Framework?

Di Pertemuan 1–2 kita sudah menulis JavaScript yang mengubah halaman lewat DOM. Untuk halaman kecil itu cukup. Untuk aplikasi dengan daftar, filter, dan form, kita harus mengingat sendiri bagian halaman mana yang perlu diperbarui setiap data berubah.

JavaScript murni (imperatif)
Data berubah → kita cari elemennya, hapus isinya, buat elemen baru satu per satu, lalu pasang lagi. Lupa satu langkah, tampilan dan data tidak sinkron.
Framework (deklaratif)
Kita cukup menulis tampilan itu seperti apa untuk data tertentu. Saat data berubah, framework yang memperbarui halaman.

1.2 Apa Itu Vue?

Vue (dibaca “view”) adalah framework JavaScript untuk membangun UI. Dibuat oleh Evan You dan dirilis pertama kali tahun 2014; kini open source dan dikembangkan komunitas.

  • Template berbasis HTML. Tampilan ditulis dengan HTML biasa yang diberi sintaks tambahan ({{ nama }}, v-for, @click). Bagi yang sudah terbiasa dengan Blade, bentuknya terasa akrab.
  • Reactivity otomatis. Data yang dibungkus ref dipantau Vue. Saat nilainya berubah, bagian halaman yang memakainya diperbarui sendiri.
  • Satu file per component (.vue). HTML, JavaScript, dan CSS satu component dikumpulkan dalam satu file.
  • “Progressive”. Vue bisa dipakai bertahap, dari sekadar menghidupkan satu bagian halaman sampai aplikasi lengkap. Di mata kuliah ini kita memakai bentuk aplikasi lengkap.
  • Banyak hal sudah tersedia: v-model untuk form, CSS yang terbatas per component (scoped), dan library resmi untuk routing (Vue Router) serta state bersama (Pinia).
Kita memakai Vue 3 dengan gaya Composition API (<script setup>, ref, computed). Tutorial lama di internet sering memakai gaya Options API (data(), methods). Itu Vue yang sama dengan cara penulisan berbeda; bila bertemu, jangan bingung.

1.3 Apa Itu React?

React adalah library JavaScript untuk membangun UI. Dibuat di Facebook (sekarang Meta) dan dibuka sebagai open source tahun 2013.

  • Library, bukan framework lengkap. React hanya mengurus tampilan: component dan state. Hal lain seperti routing tidak ikut; kita memasang library terpisah (React Router di Section 14). Vue pun memakai library terpisah untuk routing, tetapi yang resmi sudah disiapkan timnya.
  • Component adalah fungsi JavaScript yang mengembalikan tampilan, ditulis dengan JSX (sintaks mirip HTML di dalam JavaScript). Hampir semuanya JavaScript biasa: perulangan dengan .map(), kondisi dengan ternary.
  • Data mengalir satu arah: dari component induk ke anak lewat props. Perubahan data dilakukan lewat fungsi khusus (setter milik useState), lalu React menggambar ulang tampilan.
  • Ekosistem sangat besar dan banyak dipakai di industri. Konsep yang sama juga dipakai di React Native untuk aplikasi mobile.
Satu ide yang dipakai keduanya: Virtual DOM. Mengubah DOM asli (pohon elemen halaman, Pertemuan 1–2) itu mahal. Vue dan React menyimpan salinan ringan dari tampilan di memori; saat data berubah mereka membandingkan salinan lama dan baru, lalu hanya mengubah bagian DOM yang benar-benar berbeda. Kita tidak mengurus ini sendiri, tetapi inilah alasan menulis “tampilan untuk data tertentu” bisa tetap cepat.

2. Buat Project Vue Indikator 6.1

b. npx dan npm create: Menjalankan Program Tanpa Memasangnya

Untuk membuat project baru kita butuh sebuah generator, program yang menyusun folder dan konfigurasi awal supaya tidak ditulis satu per satu. Generator itu tidak kita pasang permanen; kita cukup menjalankannya sekali. Itulah fungsi npx: mengunduh sebuah paket dari npm ke tempat sementara, menjalankan programnya, lalu selesai.

npm create vite@latest nama-project adalah singkatan dari npm init vite@latest nama-project, yang artinya: “cari paket bernama create-vite di npm, jalankan, dan beri nama project nama-project”. Karena itu di output nanti tertulis > npx dan > cva ...: npm memanggil npx, dan cva adalah nama program di dalam paket create-vite.

c. Vite: Menjalankan dan Membangun Project Front End

Vite (dibaca “vit”, bahasa Prancis untuk “cepat”) adalah build tool untuk project front end. Dibuat oleh Evan You, pembuat Vue, tetapi tidak terikat pada Vue: React dan framework lain juga memakainya.

Mengapa dibutuhkan? Browser hanya mengerti HTML, CSS, dan JavaScript standar. Padahal kode kita memakai file .vue dan .jsx (bukan format standar), dan import { ref } from 'vue' (browser tidak tahu di mana “vue” berada). Vite menerjemahkan semua itu menjadi sesuatu yang bisa dijalankan browser.

3. Template & Reactivity Indikator 6.1 & 6.2

Ada dua ide utama di Vue. Pertama, template: HTML yang bisa menampilkan data dengan {{ }}. Kedua, reactivity: data yang dibungkus ref otomatis memperbarui tampilan saat nilainya berubah.

SintaksFungsinyaContoh

3.1 Praktik: Satu Mahasiswa, Dua Tombol

Ganti seluruh isi src/App.vue. Belum ada component lain; ini hanya untuk merasakan ref, @click, dan computed:

src/App.vue (ganti seluruh isi)
<script setup>
import { ref, computed } from 'vue'

const nama = ref('Andi')
const semester = ref(6)
const ipk = ref(3.75)

const predikat = computed(() => {
  if (ipk.value >= 3.5) return 'Sangat Memuaskan'
  if (ipk.value >= 2.75) return 'Memuaskan'
  return 'Cukup'
})

function naikSemester() {
  semester.value++
}

function turunkanIpk() {
  ipk.value = Math.max(0, ipk.value - 0.5)
}
</script>

<template>
  <h1>Daftar Mahasiswa</h1>

  <p>{{ nama }} - semester {{ semester }}, IPK {{ ipk.toFixed(2) }}</p>
  <p :class="{ rendah: ipk < 2.75 }">Predikat: {{ predikat }}</p>

  <button @click="naikSemester" :disabled="semester >= 14">Naik semester</button>
  <button @click="turunkanIpk">IPK -0.5</button>
</template>

<style>
.rendah {
  color: #b91c1c;
  font-weight: bold;
}
</style>

Penjelasan bagian yang baru:

  • ref(6) membungkus angka 6 menjadi object dengan satu properti .value. Di bagian script, baca dan ubah lewat semester.value. Di <template> cukup tulis semester; Vue membuka bungkusnya sendiri.
  • computed(() => ...) menghitung predikat dari ipk. Saat ipk berubah, predikat dihitung ulang otomatis. Kita tidak memanggilnya seperti fungsi (predikat, bukan predikat()).
  • :class="{ rendah: ipk < 2.75 }": class rendah dipasang hanya saat kondisinya benar.
  • :disabled: tombol mati saat semester sudah 14.
  • @click="naikSemester" tanpa kurung: mengoper fungsinya, bukan memanggilnya saat render.

6.1 Praktik: Component Form

Aturan validasi sengaja sama dengan skema Joi di backend (Pertemuan 5): NIM 9 karakter, nama minimal 3 karakter, IPK 0–4, semester bilangan bulat 1–14. Buat src/components/FormMahasiswa.vue:

src/components/FormMahasiswa.vue (file baru)
<script setup>
import { reactive, ref } from 'vue'

const emit = defineEmits(['simpan'])

const form = reactive({ nim: '', nama: '', ipk: 0, semester: 1 })
const error = ref({})

function validasi() {
  const e = {}
  if (form.nim.length !== 9) e.nim = 'NIM harus 9 karakter'
  if (form.nama.length < 3) e.nama = 'Nama minimal 3 karakter'
  if (typeof form.ipk !== 'number' || form.ipk < 0 || form.ipk > 4) e.ipk = 'IPK harus angka antara 0 dan 4'
  if (!Number.isInteger(form.semester) || form.semester < 1 || form.semester > 14) {
    e.semester = 'Semester harus bilangan bulat 1 sampai 14'
  }
  return e
}

function kirim() {
  error.value = validasi()
  if (Object.keys(error.value).length > 0) return

  emit('simpan', { ...form })

  form.nim = ''
  form.nama = ''
  form.ipk = 0
  form.semester = 1
}
</script>

<template>
  <form class="form" @submit.prevent="kirim" novalidate>
    <h2>Tambah Mahasiswa</h2>

    <label>
      NIM
      <input v-model.trim="form.nim" />
      <small v-if="error.nim" class="salah">{{ error.nim }}</small>
    </label>

    <label>
      Nama
      <input v-model.trim="form.nama" />
      <small v-if="error.nama" class="salah">{{ error.nama }}</small>
    </label>

    <label>
      IPK
      <input v-model.number="form.ipk" type="number" step="0.01" />
      <small v-if="error.ipk" class="salah">{{ error.ipk }}</small>
    </label>

    <label>
      Semester
      <input v-model.number="form.semester" type="number" />
      <small v-if="error.semester" class="salah">{{ error.semester }}</small>
    </label>

    <button type="submit">Simpan</button>
  </form>
</template>

Di Vue, data yang berubah dibungkus ref. Di React namanya state, dibuat dengan useState. Fungsi yang namanya diawali use disebut hook. Hook hanya boleh dipanggil di bagian paling atas component, tidak di dalam if atau perulangan.

src/App.jsx (ganti seluruh isi)
import { useState } from 'react'
import { mahasiswaAwal } from './data/mahasiswa.js'
import KartuMahasiswa from './components/KartuMahasiswa.jsx'

function App() {
  const [daftar, setDaftar] = useState(mahasiswaAwal)
  const [filterSemester, setFilterSemester] = useState(null) // null = semua semester

  const tampil =
    filterSemester === null ? daftar : daftar.filter((m) => m.semester === filterSemester)

  function hapus(id) {
    setDaftar(daftar.filter((m) => m.id !== id))
  }

  return (
    <>
      <h1>Daftar Mahasiswa</h1>

      <div className="filter">
        <button onClick={() => setFilterSemester(null)} className={filterSemester === null ? 'aktif' : ''}>
          Semua
        </button>
        <button onClick={() => setFilterSemester(4)} className={filterSemester === 4 ? 'aktif' : ''}>
          Semester 4
        </button>
        <button onClick={() => setFilterSemester(6)} className={filterSemester === 6 ? 'aktif' : ''}>
          Semester 6
        </button>
      </div>

      {tampil.length === 0 ? (
        <p className="kosong">Tidak ada mahasiswa untuk filter ini.</p>
      ) : (
        <div className="daftar">
          {tampil.map((m) => (
            <KartuMahasiswa key={m.id} {...m} onHapus={hapus} />
          ))}
        </div>
      )}
    </>
  )

src/components/FormMahasiswa.jsx (file baru)
import { useState } from 'react'

const formKosong = { nim: '', nama: '', ipk: '0', semester: '1' }

function validasi(data) {
  const e = {}
  if (data.nim.trim().length !== 9) e.nim = 'NIM harus 9 karakter'
  if (data.nama.trim().length < 3) e.nama = 'Nama minimal 3 karakter'
  const ipk = Number(data.ipk)
  if (data.ipk === '' || Number.isNaN(ipk) || ipk < 0 || ipk > 4) {
    e.ipk = 'IPK harus angka antara 0 dan 4'
  }
  const semester = Number(data.semester)
  if (data.semester === '' || !Number.isInteger(semester) || semester < 1 || semester > 14) {
    e.semester = 'Semester harus bilangan bulat 1 sampai 14'
  }
  return e
}

function FormMahasiswa({ onSimpan }) {
  const [form, setForm] = useState(formKosong)
  const [error, setError] = useState({})

  function ubah(e) {
    setForm({ ...form, [e.target.name]: e.target.value })
  }

  function kirim(e) {
    e.preventDefault()
    const hasil = validasi(form)
    setError(hasil)
    if (Object.keys(hasil).length > 0) return

    onSimpan({
      nim: form.nim.trim(),
      nama: form.nama.trim(),
      ipk: Number(form.ipk),
      semester: Number(form.semester),
    })
    setForm(formKosong)
  }

  return (
    <form className="form" onSubmit={kirim} noValidate>
      <h2>Tambah Mahasiswa</h2>

      <label>
        NIM
        <input name="nim" value={form.nim} onChange={ubah} />
        {error.nim && <small className="salah">{error.nim}</small>}
      </label>

      <label>
        Nama
        <input name="nama" value={form.nama} onChange={ubah} />
        {error.nama && <small className="salah">{error.nama}</small>}
      </label>

      <label>
        IPK
        <input name="ipk" type="number" step="0.01" value={form.ipk} onChange={ubah} />
        {error.ipk && <small className="salah">{error.ipk}</small>}
      </label>

      <label>
        Semester
        <input name="semester" type="number" value={form.semester} onChange={ubah} />
        {error.semester && <small className="salah">{error.semester}</small>}
      </label>

      <button type="submit">Simpan</button>
    </form>
  )
}

export default FormMahasiswa
  • Semua field disimpan sebagai teks di satu state object form. Input angka tetap menghasilkan teks, jadi konversi dilakukan sekali di Number(form.ipk) saat validasi dan saat mengirim.
  • setForm({ ...form, [e.target.name]: e.target.value }): satu handler ubah untuk semua input. Atribut name pada input menentukan field mana yang diubah ([...] adalah computed property key). Spread ...form menyalin field lain karena state tidak boleh diubah di tempat.
  • validasi(data) berada di luar component karena tidak butuh state; fungsi murni yang mengembalikan object pesan error.
  • data.ipk === '' menangkap input yang dikosongkan; tanpa ini Number('') bernilai 0 dan lolos.
  • setForm(formKosong) mengosongkan form setelah data valid dilaporkan lewat onSimpan.
