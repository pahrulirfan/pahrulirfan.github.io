Array Function Tugas 2

Tujuan: mahasiswa memahami dan mampu menggunakan 6 metode penting Array di JavaScript: map(), filter(), reduce(), find(), some(), dan every(). Kalian akan membuat data array sendiri, lalu menerapkan keenam metode itu dengan kasus yang berbeda untuk tiap metode. Rujukan konsepnya ada di Section 1 Materi 2.

Instruksi

  1. Buat sebuah file JavaScript dengan nama arrayMethods_NIM.js (contoh: arrayMethods_FD2200123.js).
  2. Gunakan data array buatan sendiri, minimal 10 elemen.
    • Setiap mahasiswa harus membuat data array yang unik berdasarkan identitas masing-masing.
    • Misalnya memakai nama teman sekelas, angka dari NIM, atau hobi pribadi (lihat Contoh Bentuk Data di bawah).
  3. Terapkan keenam metode (map, filter, reduce, find, some, every) dengan contoh kasus yang berbeda untuk tiap metode. Contoh kasus jika datanya berupa daftar nama:
    • map() → ubah semua nama menjadi huruf besar.
    • filter() → ambil nama yang panjangnya lebih dari 5 huruf.
    • reduce() → hitung total panjang semua nama.
    • find() → cari nama tertentu (misalnya huruf depan sama dengan huruf depan nama kalian).
    • some() → cek apakah ada nama dengan panjang lebih dari 10 huruf.
    • every() → cek apakah semua nama terdiri dari lebih dari 3 huruf.
  4. Kalian bebas memilih kasus, tetapi harus konsisten dengan data array yang dibuat sendiri.
  5. Buat screenshot:
    • Screenshot kode program untuk setiap metode.
    • Screenshot hasil eksekusi kode di console/terminal/browser.

Contoh Bentuk Data

Berikut tiga contoh bentuk array supaya kalian punya gambaran. Ini hanya contoh: data di tugas kalian harus berbeda, buatan sendiri, dan berisi minimal 10 elemen (contoh di bawah sengaja dipendekkan menjadi 5 elemen).

Contoh 1 — Array of string (daftar nama)

const namaTeman = [
    "Andi", "Budi", "Citra", "Dewi", "Eko",
    // ... lanjutkan sampai minimal 10 nama
];

Cocok untuk kasus dasar seperti contoh di atas: huruf besar, panjang nama, huruf depan.

Contoh 2 — Array of number (angka dari NIM)

// NIM F1D022045 → ambil digit / potongan angkanya
const angkaNim = [
    1, 0, 2, 2, 0, 4, 5,
    // ... boleh ditambah angka lain (tanggal lahir, nomor favorit, dst.) sampai minimal 10
];

Kasus yang cocok, misalnya: map() mengalikan tiap angka, filter() mengambil angka genap, reduce() menjumlahkan semuanya, every() mengecek apakah semua angka ≥ 0.

Contoh 3 — Array of object (hobi pribadi)

const hobi = [
    { nama: "Membaca",   jamPerMinggu: 5,  outdoor: false },
    { nama: "Futsal",    jamPerMinggu: 3,  outdoor: true  },
    { nama: "Gaming",    jamPerMinggu: 12, outdoor: false },
    { nama: "Memancing", jamPerMinggu: 4,  outdoor: true  },
    { nama: "Memasak",   jamPerMinggu: 2,  outdoor: false },
    // ... lanjutkan sampai minimal 10 hobi
];

Bentuk ini paling mirip data sungguhan (hasil SELECT atau JSON dari API). Kasus yang cocok, misalnya: map() mengambil nama hobinya saja, filter() mengambil hobi outdoor, reduce() menjumlahkan jamPerMinggu, find() mencari hobi bernama tertentu.

Catatan: kasus pada Instruksi no. 3 ditulis untuk array nama. Jika datamu berupa angka atau object, sesuaikan kasusnya (kondisi di filter, some, dan every mengikuti isi datamu), tetapi keenam metode tetap wajib dipakai dan tiap metode memakai kasus yang berbeda.
