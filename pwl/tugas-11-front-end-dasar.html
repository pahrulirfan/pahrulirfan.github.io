Tugas 11 — Front End Dasar (Vue)

Pertemuan 11, lanjutan dari Materi 11: Front End Dasar

Menampilkan Data dengan Vue Router Tugas 11

Tujuan: membuat aplikasi Vue dengan minimal 4 halaman yang menampilkan data dan berpindah halaman lewat Vue Router. Rujukan: Materi 11, Section 2–5 dan Section 7.

Proyek Dasar

  1. Buat repository T11-VUE-ROUTER. Project Vue dibuat langsung di akar repository (Materi 11, Section 2.3), dengan Vue Router (Section 7).
  2. Kerjakan dari project kosong buatan sendiri, bukan menyalin vue-mahasiswa lalu mengganti nama.

Bagian 1 — Data

Pilih tema sendiri: buku, film, resep, menu kafe, destinasi wisata, dan sejenisnya (kecuali mahasiswa dan matakuliah, karena sudah jadi contoh di materi). Contoh di bawah memakai buku; ganti dengan tema kalian. Simpan datanya di src/data/ sebagai array, seperti mahasiswa.js di Section 5.1:

export const bukuAwal = [
  { id: 1, judul: 'Laskar Pelangi', penulis: 'Andrea Hirata', tahun: 2005 },
  // ... minimal 6 data
]
  • Minimal 6 data yang masuk akal, dengan minimal 4 field termasuk id yang unik.

Bagian 2 — Halaman dan Rute

Nama rute mengikuti tema data kalian. Tabel di bawah memakai buku sebagai contoh. Kalau temanya film, rutenya /film dan /film/:id; kalau resep, /resep dan /resep/:id, dan seterusnya. Nama halaman dan file view juga disesuaikan (mis. FilmView.vue).

RuteHalamanIsi
/BerandaSambutan singkat dan tautan ke daftar
/bukuDaftarSeluruh data ditampilkan dengan v-for dan :key (kartu atau tabel), tiap item punya tautan ke detail
/buku/:idDetailSemua field satu data. Bila id tidak ada, tampil pesan “tidak ditemukan” dan tautan kembali
/tentangTentangNama dan NIM, serta jumlah data (dihitung dari array, bukan ditulis manual)
/:pathMatch(.*)*404Wajib ada, tidak dihitung dalam 4 halaman
  • Menu di atas berisi RouterLink ke Beranda, Daftar, dan Tentang. Tautan halaman yang sedang aktif diberi gaya berbeda.
  • Perpindahan halaman memakai RouterLink atau router.push, tidak memakai <a href> biasa yang memuat ulang halaman.
  • Halaman Detail mengambil id dari useRoute(). Awas: route.params.id bertipe teks, sedangkan id di data berupa angka.
  • Memecah tampilan menjadi component (misalnya KartuBuku) tidak diwajibkan, tetapi boleh.

Pengujian

Jalankan npm run dev, lalu lakukan tiga hal ini dan tunjukkan hasilnya lewat screenshot. Sertakan juga screenshot npm run build yang berhasil. Alamat /buku/999 di bawah disesuaikan dengan rute tema kalian.

NoSkenarioHasil yang diharapkan
1Pindah halaman lewat menuKonten berganti tanpa muat ulang halaman, dan tautan aktif berubah
2Buka satu detail dari daftar, lalu buka /buku/999Detail sesuai data yang diklik; id yang tidak ada menampilkan pesan dan tautan kembali
