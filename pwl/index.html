Pemrograman Web Lanjut

Silabus & Daftar Materi

Daftar materi mata kuliah Pemrograman Web Lanjut per pertemuan, mengikuti Rencana Pembelajaran Semester (RPS). Setiap pertemuan memuat penjelasan konsep dan bagian praktik (hands-on) sendiri. Kartu bertanda "Materi updated" sudah diperbarui; Pertemuan 13–15 belum. Keterangan tugas ada di tiap kartu: tugas resmi (RTM) dicek di Berajah, tugas lainnya diberikan di kelas.

Blok 1 — Fondasi JavaScript & Lingkungan Kerja

1

Lingkungan Kerja Web Modern

Arsitektur web modern, peta padanan Laravel → JavaScript, Node.js & npm, JavaScript vs PHP, dan penyiapan PostgreSQL lokal.

Sub-CPMK 1Materi updated Tugas: diberikan di kelas. 2

Metode Array & Destrukturisasi

Rantai map/filter/reduce/find/some/every untuk mengolah data JSON, destrukturisasi, spread, dan optional chaining.

Sub-CPMK 1Materi updated Tugas: diberikan di kelas. 3

Modul & Pemrograman Asinkron

ESM vs CommonJS, Promise, async/await, fetch, penanganan error asinkron, dan eksekusi berurutan vs serentak.

Sub-CPMK 2Materi updated Tugas RTM I: cek di Berajah.

Blok 2 — REST API & Basis Data

4

REST API Dasar dengan Express dan GraphQL

Prinsip REST, perancangan sumber daya, routing Express, req.params/query/body, kode status HTTP, dan pengenalan GraphQL.

Sub-CPMK 3Materi updated Tugas: diberikan di kelas. 5

Middleware & Error Terpusat

Middleware dan urutannya, penanganan error terpusat, struktur proyek berlapis, dan pengujian dengan REST client.

Sub-CPMK 3Materi updated Tugas RTM II: cek di Berajah. 6

ORM, Skema & Migrasi

Dari tabel manual dan SQL ke Prisma sebagai ORM, CRUD lengkap, migrasi, relasi satu-ke-banyak dan banyak-ke-banyak, serta normalisasi.

Sub-CPMK 4Materi updated Tugas RTM III: cek di Berajah. 7

Kueri Lanjutan & Transaksi

Paginasi, filter, pengurutan, transaksi basis data, data awal (seed) yang dapat diulang, dan dokumentasi endpoint.

Sub-CPMK 4Materi updated Tugas: diberikan di kelas.
8

Evaluasi Tengah Semester (ETS)

Mini proyek individu berupa API utuh (Materi Minggu 1–7, Sub-CPMK 1–4) disertai video penjelasan. Penilaian lewat pemeriksaan luaran dan tanya jawab.

ETS — 22% Pengumpulan: link repositori dan file video lewat Berajah. Ketentuan lengkap cek di Berajah.

Blok 3 — Keamanan, Antarmuka & Integrasi

9

Autentikasi & Otorisasi

Hashing kata sandi dengan bcrypt, sesi vs token (JWT), implementasi login, dan otorisasi berbasis peran.

Sub-CPMK 5Materi updated Tugas: diberikan di kelas. 10

Keamanan Aplikasi & Pengujian

OWASP Top 10, header keamanan, rate limiting, perkakas uji otomatis (ZAP, npm audit), dan laboratorium Juice Shop.

Sub-CPMK 5Materi updated Tugas: diberikan di kelas. 11

Front End Dasar

Vue (inti) dan React: buat project dengan Vite, component & props, state & event, list & kondisi, data binding & form, dan routing beberapa halaman.

Sub-CPMK 6Materi updated Tugas RTM IV: cek di Berajah. 12

Integrasi API-Frontend

Menyambungkan Vue dan React ke API sendiri: CORS, fetch + .env, state loading/error/kosong, login & token, tambah/hapus, dan code review. API siap pakai ada di repo pahrulirfan/project-pwl-26.

Sub-CPMK 6Materi updated Tugas: diberikan di kelas.

Blok 4 — Pengujian & Rilis

13

Pengujian Otomatis & CI

Piramida pengujian, unit testing (Vitest), end-to-end (Playwright), uji regresi keamanan, dan pipeline integrasi berkelanjutan.

Sub-CPMK 7 Tugas RTM V: cek di Berajah.
14

Build Produksi & Rilis

Build produksi API dan antarmuka, variabel environment, migrasi ke basis data rilis, dan rilis ke layanan hosting.

Sub-CPMK 8 Tugas: diberikan di kelas.
15

Core Web Vitals & Aksesibilitas

Mengukur LCP/INP/CLS, audit aksesibilitas WCAG 2.2, uji jalur cadangan, dan gladi demonstrasi.

Sub-CPMK 8 Tugas: diberikan di kelas.
16

Evaluasi Akhir Semester (EAS)

Demonstrasi produk kelompok yang sudah berjalan (Materi Minggu 9–15, Sub-CPMK 5–8), disertai wawancara kode per individu.

EAS — 30% Pengumpulan: link aplikasi, repositori, dan dokumentasi lewat Berajah. Ketentuan lengkap cek di Berajah.
